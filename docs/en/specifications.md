# Compliance Matrix

This document provides a list of specifications that are currently being evaluated by the coalition. The full and finalized evaluation will be made public here as soon as it is completed.

### Public Transport 🚋 

| Name | Full Name | Link | Function |
|---|---|---|---|
| Always Compliant |  |  |  |
| GTFS Schedule | General Transit Feed Specification Schedule |  | Travel information: Transit schedules, geography, fares. |
| GTFS Realtime | General Transit Feed Specification Realtime |  | Extends GTFS to support live updates. |
| TODS | Transit Operational Data Standard |  | Extends GTFS for personnel and non-revenue service information used in scheduled transit operations. |
| TIDES | Transit Integrated Data Exchange Specification |  | Standard format for archiving transit operational data (AFC, AVL, APC). |
| Transmodel | European Reference Data Model for Public Transport |  | Conceptual reference model for all CEN public transit data structures.  See NeTEx, SIRI, OpRa. |
| NeTEx | Network, Timetables and Fare Exchange, CEN TS 16614-1 to 3 (SG9) |  | Exchange of network, schedules, and complex fare data. |
| SIRI | Service Interface for Real Time Information |  | Exchange of realtime information about schedules, vehicles, transfers, and additional informational messages about operational status |
| OpRa | Operational Raw Data |  | Archive of observed data about transit operations for future planning |
| OJP | Open Journey Planner |  | Defines an open API standard for distributed journey planning. It allows different systems and agencies to collaborate and calculate cross-border or multi-modal trips without needing a central data repository. |
| ITxPT | Information Technology for Public Transport |  | IT architecture for public transport, currently focused on on-vehicle communication |
| GTNS | General Travel Network Specification |  | Aims to describe travel model networks for faster transportation planning. Planned specification. Might be related to a similar project: General Modeling Network Specification (GMNS) |
| GMNS | General Modeling Network Specification |  | Provides a common machine- and human-readable format for sharing routable road and multi-modal network files. Used primarily for static and dynamic transportation planning and operations modeling. |
| VDV | Verband Deutscher Verkehrsunternehmen - Kernapplikation (VDV-KA) |  | Nationwide open data and interface standard for electronic ticketing and electronic fare management (EFM) in public transport across smart cards, 2D barcodes, mobile NFC ticketing, and background processing systems. |
| TransXChange | TransXChange (TXC) |  | UK national XML-based standard for modeling and exchanging bus routes, stops, and timetables, used for passenger information systems and regulatory registration (Electronic Bus Service Registration / EBSR). |
